# PrivatFinanz – Info-Seiten

Dieses Repository enthält ausschließlich die öffentlich erreichbaren Informationsseiten für das private Android-Projekt PrivatFinanz.

- `index.html` – Startseite
- `privacy.html` – Datenschutzhinweise
- `terms.html` – Nutzungsbedingungen

## GitHub Pages aktivieren

Repository > Settings > Pages > Build and deployment > Source: `Deploy from a branch` > Branch: `main`, Ordner: `/(root)` > Save.

Danach unter `https://DEIN-USERNAME.github.io/privatfinanz/` prüfen.

**Sicherheitswarnung:** In dieses öffentliche Repository gehören niemals API-Schlüssel, private RSA-Schlüssel, Banking-PINs, TANs oder echte Kontodaten.

Vor dem produktiven Einsatz müssen die Texte mit der tatsächlichen Architektur und Datenverarbeitung abgeglichen werden.
